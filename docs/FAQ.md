# 常见问题

[返回首页](../README.md)

第一次使用请先看 [零基础安装步骤](BEGINNER.md)。不会打开 .md 文件时，双击解压目录的 START-HERE.html 即可。

### 原生版和增强版都要安装吗？

不用。原生版是宿主加载的皮肤，增强版自带播放帧和窗口。增强版并不是向官方桌宠添加额度气泡；两个窗口是独立程序。

### 为什么原生版没有额度？

`pet.json` 和精灵图只定义外观，不能给官方宿主增加自定义额度面板。需要本项目的额度和任务增强功能，请按系统选择 Windows 或 macOS 增强版。

### 适配 Mac 吗？

0.2.0 新增 macOS Electron 增强版源码与 .app 构建入口，要求 macOS 13+，可分别为 Apple Silicon / Intel 构建。跨平台代码与界面已测试，Mac 实机、签名/公证待验收；不是把 Windows 程序直接搬过去。原生素材也可由兼容 v2 的 Mac 宿主加载。完整步骤见 [Mac 指南](MACOS.md)。

### 任务已结束，却一直显示“思考中”？

0.2.3 进一步适配新版 Codex 的结构化审批记录：只有桌面确实显示审批窗口或会话明确等待用户输入时才显示“等待批准”，Codex 自动审查权限期间保持“进行中”；批准或拒绝只解除匹配的请求，任务完成后恢复空闲。0.1.2 起也会核对本机会话的完成与中止事件，不依赖“弹出完成通知”日志。更新后必须退出并重新启动增强版。若数据桥退出或超过 15 秒没有活动心跳，会显示“状态离线”。若仍不准确，请反馈客户端版本及时间点，不要提交原始日志/会话记录。

### 双击 Start.vbs 没反应？

先完整解压，检查 Node.js 是否安装、`node --version` 是否可运行，以及是否已有旧版 / 新版在运行。项目做了单实例保护，第二次启动不会再出现一只。错误提示可通过 `Start-Debug.cmd` 查看；若组织或系统禁止 VBScript，改用安装指南中的 PowerShell 入口。

### 为什么有一个 CMD / PowerShell 窗口？

正常入口是 `Start.vbs`，它隐藏终端。`Start-Debug.cmd` 专门保留错误输出，手动在终端启动也会依附该终端；这些都不是常驻使用的默认入口。

### 为什么一直连接中、状态离线或没有额度？

先在 Codex 中确认登录有效并能正常工作，再右键刷新。增强版依赖本机可用的 Codex app-server 及桌面日志；找不到 CLI 时可指定 `CODEX_EXE`。不同客户端版本、安装方式、账号接口和日志格式都可能影响读取。API Key 登录等情形不保证提供 ChatGPT 订阅额度。项目无法伪造额度，也不会要求你上传 `auth.json` 来排错。

### “重置 --”和“重置 ×0”有什么区别？

`--` 表示接口没有返回可用次数，`×0` 表示接口明确提供了零次可用重置。它只是信息标签，点击不会兑换重置。倒计时也是额度窗口刷新时间，不代表可以人为增加额度。

### 明明有任务在执行，为什么不是思考动作？

多任务时优先级为：需要确认 → 出错 → 完成 → 执行中 → 空闲。先展开活动面板查看其他任务；完成 / 错误提醒可手动清除。单个执行中的任务保持思考状态，动画不会因为鼠标移开就主动恢复空闲。状态结合日志与本机会话事件；远程任务、本地文件缺失或客户端格式变化仍可能导致失准。

### 活动列表为什么和 Codex 侧栏数量不同？

列表是观察到的近期活动，不是全部历史任务。完成与错误提醒保留约 10 分钟；长期没有更新的运行 / 等待记录约 12 小时后失效。它不保证覆盖云端、其他设备、所有 CLI 会话或多个账号。

### 出错动作为什么与原生版速度不同？

增强版从 `animation-timing.json` 读取节奏，出错循环为 3.6 秒，且同一状态的刷新不会让动作重新开始。原生版的时序由官方宿主决定；两版使用相同的小幅度出错动作，但不能通过图集把官方宿主的帧率也改成增强版的设置。首页 GIF 展示增强版节奏，原生节奏的 GIF 单独放在 `docs/animations/native/`。

### 双击后会不会回到初始页面？

Mac 使用系统方式激活所选应用，不主动导航到首页；多个窗口中恢复哪个由 macOS 决定，不能保证精确恢复某个历史窗口。以下窗口句柄逻辑仅适用于 Windows。

增强版会先恢复已有的 Codex 窗口，不通过“新任务”链接打开它。已有进程但找不到可恢复窗口、或系统拒绝切换焦点时会报错，不会为此新建任务。只有 Codex 完全退出时才尝试启动应用。多窗口情况下优先恢复之前记录的 Codex 窗口；该记录仅在当前助手进程内有效。

### 任务跳转和系统通知有什么限制？

Mac 有默认关闭的“系统完成通知”开关，受系统权限控制；仍保留面板和文字提醒。以下关于不推送通知中心的描述针对 Windows。

点击列表使用 `codex://threads/<任务ID>`，只适用于本机客户端能打开的任务。完成提醒表现为桌宠动作、文字和活动列表，不是 Windows 通知中心的推送，也不播放声音。[官方深层链接说明](https://learn.chatgpt.com/docs/reference/commands#deep-links)

### 如何只留下小桌宠？找不到气泡怎么办？

Mac 同样从右键分别隐藏面板，可从菜单栏找回位置。尺寸为纯桌宠 132×182、额度 410×190、仅任务 410×256、两面板 410×374（逻辑点）。以下尺寸仅指 Windows。

右键分别隐藏额度气泡和任务队列，窗口会变成 128 × 180 的布局。右键可随时重新显示。常规布局 344 × 180，展开任务时 344 × 344（均为逻辑尺寸，实际像素随缩放变化）。程序会限制窗口在工作区内。

### Mac 为什么还出现终端？怎样登录后自动显示？

`npm start` 是前台调试入口。日常用构建后的 `.app`，无需终端；`Start.command` 会短暂开终端，启动后可关闭。Mac 跟随显示仅在桌宠运行时工作，登录启动需另外设置；未签名构建的登录项不能保证有效，见 [Mac 指南](MACOS.md)。
