# 隐私与本地数据

## 读取什么

本项目由个人制作和维护；Windows 与 Mac 增强版共用本地数据桥，原生版不包含它。

原生素材版仅提供 `pet.json` 和透明图集，不包含读取账号数据的脚本。

独立增强版在本机读取 Codex 额度、可用重置次数（若接口提供）、任务元数据及桌面日志中的状态事件。任务标题可能来自 app-server 的名称 / 预览字段或本机 `session_index.jsonl`。桌面日志本身可能包含敏感信息，程序会读取有限范围以解析状态，不应把原始日志公开上传。

程序借助 Codex 自己的已登录环境工作。它不要求把访问令牌复制进项目，也不提供登录信息上传功能。

0.1.2 起还读取 `CODEX_HOME/sessions`（默认 `.codex/sessions`）下已被桌面观察到的任务会话文件：首次取最多 4 MiB 尾部，后续增量读取，提取开始、完成、中止等生命周期字段。0.2.2 另读取最多 256 KiB 头部中的会话元数据，确认主任务来源并排除子 agent、内部临时会话；0.2.3 读取结构化工具调用的名称、明确的权限/用户输入请求标记和请求 ID，用于显示及解除“等待批准”，不会把普通自动审查标记保存为等待。程序只缓存来源分类和生命周期状态，不保存完整头部、工具参数或输出。读取的字节范围可能同时包含对话和工具输出，但这些内容不另存、不发送。仅遍历目录不会把未观察到的历史任务加入面板。会话记录与原始桌面日志都不要上传到 GitHub。

## 保存在哪里

Mac 默认为 `~/Library/Application Support/BJUT-YanXiaoBei/`：`mac-settings.json` 保存显示开关、应用/CLI 路径与位置，`bridge-state.json` 保存状态，源码后台启动器可能写 `launcher.log`，Electron 还可能生成本地缓存。不要将这些文件上传仓库。关闭后可移走此目录以重置，不必删除 Codex 账号目录。

Mac 没有兼容桌面日志时，会从 app-server 返回的近期根任务定位会话记录（排除识别出的 sub-agent），因此范围可能包含近期本机 CLI 活动；不是仅当前可见窗口。仍只保存生命周期和标题，不保存完整对话。Mac 系统完成通知默认关闭，主动开启后可能在通知中心显示任务标题，敏感场景建议保持关闭。

默认保存到 `%LOCALAPPDATA%\BJUT-YanXiaoBei`，包括任务标题与 ID、额度状态、位置和界面偏好。此目录不是加密保险箱，请按本机账号权限保护。使用 `YANXIAOBEI_DATA_DIR` 更改路径时，不要指向公开仓库或共享目录。

## 是否发送到第三方

Mac 首次 npm 安装和 Electron 构建需要从软件分发服务下载依赖；这是软件安装流量，不会将任务缓存发送到这些服务。应用界面不加载远程网页。Electron 采用沙盒和受限 IPC。源码包不含 node_modules、打包缓存、签名证书或密钥。

本项目没有自己的遥测服务或云端数据库，也不把状态主动发送给项目维护者。Node 数据桥通过本地进程管道调用 Codex；Codex 获取账号额度等操作仍可能按其自身机制连接 OpenAI 服务，因此这不等于整个过程完全离线。

额度标签只读取信息，不兑换重置、购买点数或发送新任务。点击任务行通过本机注册的 `codex://` 协议打开对应任务。
